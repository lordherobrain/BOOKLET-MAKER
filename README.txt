MANGA A4 BOOKLET MAKER

Install Python 3, then run:
    py -m pip install pypdf

Drag a manga PDF onto manga_booklet.py.

The output is an A4 landscape PDF arranged for:
- 2 pages per side
- double-sided/duplex printing
- folding A4 in half into an A5 booklet
- page count padded to a multiple of 4

Printer settings:
Paper A4
Orientation Landscape
Duplex ON
Flip on SHORT EDGE
Scale Actual Size / 100%

Only reproduce material you have permission to print.
